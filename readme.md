# 🕹️ Portfolio Website | Retro 80s Synthwave Style

¡Bienvenido/a al repositorio de mi portafolio web personal! Este proyecto es una vitrina interactiva diseñada para presentar mi perfil, habilidades, trayectoria y proyectos destacados, combinando una estética retro inspirada en los años 80 con tecnologías y prácticas de maquetación web.

---

## 🚀 Características Principales

* **Estética Retro 80s:** Uso de paletas de color llamativas, recursos gráficos retro, GIFs animados e imágenes creadas mediante Inteligencia Artificial para darle movimiento y una experiencia visual atractiva.
* **Navegación Fluida:** Organizado en secciones clave para facilitar la lectura y consulta de contenido.
* **Componentes Interactivos:** Botones con animaciones e interactividad funcional implementada mediante JavaScript y clases utilitarias de Bootstrap.
* **Enlace a CV:** Acceso directo a la versión de mi Curriculum Vitae.

---

## 📄 Páginas y Secciones del Sitio

1. **`Home` (Inicio):** Página de bienvenida con elementos retro visuales.
2. **`About Me` (Sobre mí):** Resumen sobre mi perfil, experiencia e intereses.
3. **`Portfolio` (Proyectos):** Muestra de mis proyectos y trabajos realizados.
4. **`Contacto` (Formulario):** Formulario de contacto integrado para recibir mensajes.
5. **`CV`:** Enlace directo para consultar mi currículum vitae.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructuración semántica de las páginas.
* **CSS3:** Estilos personalizados, colores retro y diseños adaptables.
* **JavaScript (JS):** Pequeñas funciones para activar lógica interactiva en botones y componentes.
* **Bootstrap:** Clases y componentes para maquetación e interacción rápida.
* **AI Generated Assets & GIFs:** Imágenes generadas con IA y GIFs para aportar dinamismo.

   ```bash
   git clone https://github.com/tu-usuario/tu-repositorio.git
   ```

